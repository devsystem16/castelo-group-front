# Castelo Group - Frontend React

## Comandos

```bash
# Desarrollo
npm start

# Producción (build + copia a Laravel public)
npm run build
```

## Variables de entorno (.env)
```
REACT_APP_API_URL=http://castelo-group-back.test/api
REACT_APP_WHATSAPP=593990000000
```

## Páginas implementadas
- `/` — Inicio con hero, buscador y propiedades destacadas
- `/terrenos` — Listado con filtros avanzados (provincia, tipo, precio, área)
- `/terrenos/:id` — Detalle con galería, mapa Leaflet, formulario de contacto
- `/afiliados` — Info del programa + formulario de registro
- `/oficinas` — Mapa con ubicaciones de sucursales
- `/contacto` — Formulario de contacto general
- `/login` — Inicio de sesión
- `/registro` — Registro de clientes
- `/mi-cuenta` — Dashboard del afiliado (comisiones, enlace de referido)
- `/admin` — Panel de administración completo
